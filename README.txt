V Villas GitHub Pages package

Upload these items to the ROOT of your GitHub repository:
- index.html
- .nojekyll
- assets/ (entire folder)

Then: Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
Open the GitHub Pages URL shown in Settings > Pages.
Do not open the normal github.com/.../blob/.../index.html URL; that is a source-code page, not the website.
